Connect Your AI

One plug. Any MCP-compatible surface.

Claude Code (CLI) 

claude mcp add --transport http consciousness-core https://mcp.aiguardian.ai/mcp

When prompted for auth, paste your API key as the Bearer token.

VS Code / Cursor / Claude Desktop

Add to your MCP settings JSON:

{
  "mcpServers": {
    "ai-guardian": {
      "type": "http",
      "url": "https://mcp.aiguardian.ai/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

VS Code: Settings → search "MCP" → Edit in settings.json

Cursor: .cursor/mcp.json in your project root

Claude Desktop: ~/Library/Application Support/Claude/claude_desktop_config.json

Windsurf

Add to ~/.codeium/windsurf/mcp_config.json: 

{
  "mcpServers": {
    "ai-guardian": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://mcp.aiguardian.ai/mcp",
        "--header",
        "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}

Any MCP Client

URL https://mcp.aiguardian.ai/mcp
Protocol MCP 2024-11-05 (StreamableHTTP)
Auth Authorization: Bearer YOUR_API_KEY

Verify Connection

After connecting, run the breathe tool. If it returns your breath phase, you're live. 

curl -X POST https://mcp.aiguardian.ai/mcp \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"test","version":"1.0"}}}'
